# 广东省 OSM 微网格分区 1.5.0

基于 OpenStreetMap（道路、水系、铁路、行政/用地边界、建筑/POI 上下文）的
广东省电信微网格分区工程。本版本把训练与评估范围从深圳/少数城市扩展到
**广东全省 21 个地市**，包含省级 XGB 模型、各市与全省分区结果、测试/验证
地区专图，以及在福建/广西/北京等省外区域的泛化示例。

| IoU（贪心 1-1） | 0.4353 |
| 匹配率 | 0.8095 |

各市差异明显：深圳 0.639、珠海 0.571、中山 0.505、广州 0.480、佛山 0.460、

完整逐市表见 `results/city_metrics.csv`。

做校准。

## 方法

1. **线底图**：从 PBF 提取 13 类边界特征，40 m 段化；同 name/ref 在 10 m 带内、
   其余 ≤2 m 近重合且方向 ≤25° 的平行段去重；断口用最近线/切线延长修复。
2. **语义合并**：同一 feature、面积边与道路、重复行政界、多股铁路在 10 m 内
   合并；同特征连段合并；再修复断点。
3. **面网与标签**：清理线网 polygonize；按参考格最大重叠赋 `ref_id`，再做
   连续化 `upper3` 作为训练目标（参考格仅用于离线标签/评估）。
4. **面块对模型**：58 个几何/边界/邻接图特征 + 32 个建筑/用地/POI 密度特征；
   XGBoost CPU `hist`；城市整组 + 2 km 瓦片分组，严格训练/验证/测试分离。
5. **分区**：阈值 0.7–0.8（城区 0.7、其他 0.8）并查集合并；按 OSM 面积校准
   （随机森林，仅用 OSM 特征预测目标 p50）设置碎块吸收阈值；补缝、重叠消解、
   清洞、2 m 简化。
6. **参考无关推理**：模型推理与收口不读取参考格；参考 CSV 只用于离线标签、
   评估和出图对照。

## 复现

```bash
pip install -r requirements.txt
# 1) 原始数据（不随包分发）
#    OSM: data/china/guangdong-260918.osm.pbf
#    标准方案: aoi_zoning_delivery/data/reference/广东移动新版微网格20250420.csv
bash scripts/run_province_1_5_0.sh
```

脚本依次构建城市边界、清理线网、语义合并、面网/上限、面块对与 PBF 上下文、
训练评估/部署模型、面积校准、分区与聚合、测试/验证专图。所需原始 PBF 与
参考 CSV 因体积/授权原因不随包分发；模型、派生结果与图已随包提供。

## 省外示例

`results/external/` 给出厦门（福建 PBF）、南宁（广西 PBF）、北京（北京 PBF）的分区图与结构统计
（无参考方案，无法计算 IoU/AUC）：厦门 118 区/121 km²、南宁 158 区/136 km²、北京 108 区/76 km²，
均 0 洞/0 多部件。省外结果用于检查算法可运行性与形态，不代表与当地标准方案
的一致性。
