# 深圳微网格分区数据 1.4.7（陆地版）

基于 OpenStreetMap 边界要素生成的深圳电信微网格候选分区。本包只包含最终
分区数据、字段说明、许可与预览图，不含训练代码、模型或第三方参考数据。

## 内容

```
shenzhen-zones-1.4.7-land.geojson   分区数据（WGS84）
preview.png                         全图预览
DATA_DICTIONARY.md                  字段与几何说明
LICENSE.md                          数据许可与署名
```

## 概况

- **1,682 个分区**，覆盖深圳陆域 **2,551 km²**
- 边界为**陆地行政区边界 + 海岸线**，不划领海；深汕合作区作为独立陆域包含在内
- 单部件多边形、无空洞、无区中区；相邻分区共享边界，仅 <0.001 km² 的坐标接缝误差
- 分区面积 p10/p50/p90：0.34 / 0.68 / 1.82 km²（山地等低密度区域存在大面积分区）

## 质量指标

与第三方标准微网格进行离线对比（参考数据不随包分发）：

| 指标 | 数值 |
|---|---|
| 分区数 | 1,682（参考 1,707） |
| IoU（贪心 1-1） | 0.5822 |
| 匹配率（1-1） | 0.8834 |
| 边界 F1@25 m | 0.4512 |
| 面积分布 KS | 0.1667 |
| VI（归一化） | 0.1806 |
| 版面 IoU | 0.9377 |
| 综合相似度 | 0.7424 |

IoU 为贪心一对一匹配的 IoU 均值；综合相似度为版面 IoU、IoU、匹配率、
数量比、面积 KS、VI 六项的归一化均值。指标用于衡量与第三方微网格的接近
程度，不代表对任何特定业务口径的保证。

## 使用

```python
import geopandas as gpd
z = gpd.read_file("shenzhen-zones-1.4.7-land.geojson")
print(z.crs, len(z))
```

坐标系为 EPSG:4326（WGS84 经纬度）。分区编号 `zone` 为 1..1682，
`name` 为对应的分区名。
