# 智域分区 · 可交付包

自包含的 OSM 电信治理分区服务：FastAPI 后端 + 单文件 MapLibre 前端 +
预训练 XGBoost 合并模型。复制整个目录到另一台电脑即可运行。

## 启动

```bash
python -m pip install -r requirements.txt
python run.py --port 8010
# 浏览器打开 http://127.0.0.1:8010/
```

Windows 也可运行 `start.ps1`。

## 数据

只使用本地 OSM 数据，不会联网下载。把省级 PBF 放到：

```text
data/china/<province-id>-<日期>.osm.pbf
```

`province-id` 与 `app/china_provinces.json` 一致（如 guangdong、beijing）。
在仓库内运行时，也会自动扫描仓库根的 `../data/china/`。
未放置数据的省份会提示“目前无本地 OSM 数据，暂不支持”。

参考微网格 CSV **不需要**也不应放入交付包；线上推理不读取参考数据。

## 使用流程

1. 选择省 → 市/州 → 县/区；
2. 点 **“生成所选行政区”** 才开始生成（选区不会自动出图）；
3. 阶段 + 百分比进度条；结果缓存，重复选择秒开；
4. 点击分区查看名称、面积、紧凑度、POI/建筑/路网密度、城市化、名称来源；
5. **“清除缓存与结果”** 清空生成缓存；刷新页面释放当前图层；
6. 县/区生成整县；市默认约 12×11 km 核心区；省为行政区概览。

## 算法与口径

道路/行政界/土地用途/自然/公园校园/海岸线切分 → XGBoost 判相邻块是否同区
→ 目标面积/形状约束 → 窄区/长条/凹形/碎片/飞边清理 → 无线长条近方块切分
→ 覆盖封缝/单部件 → OSM 地名命名。

- 有 OSM 线的地方贴线；没有线的地方做近方块，不做层叠长条。
- 面积/宽度/紧凑度按核心城区、非核心、乡镇/农村分场景约束。
- 线上只读 OSM；参考数据不进入任何推理特征。

## 已知限制

- 纯 OSM 无法逐线复刻人工微网格（标准约 40% 边界 OSM 不可见），
  核心城区全参考 IoU 约 0.31–0.33；但我们的边界 10 m 贴线率
  0.79–0.87，高于标准方案本身。
- 大县（>1,500 km²）精细路径较慢；沿海行政面可能含海域。
- 首次读取省级 PBF 需数秒到数十秒，缓存命中为毫秒级。
