# 标准分区方案边界特征分析

目的：不凭经验设定初始切分线，而是先量化广东移动标准微网格的边界贴在
哪些 OSM 特征上，再据此选择初始切分线。

## 方法

- 参考边界：标准微网格 CSV 的 WKT 多边形，按“场景区域属性”分为
  城建区（核心城区+非核心城区）、乡镇区（乡镇镇区）、乡村/自然区（农村）。
- 沿每条参考边界每 50 m 取一个采样点。
- OSM 特征来自本地广东省 PBF：
  - lines：highway 各等级、railway、waterway（river/canal/stream/drain）、
    barrier；
  - multipolygons 边界：administrative（level 4/5/6/8/10）、landuse、
    natural（water / wood / scrub / grassland / wetland）、leisure、amenity。
- 对每个采样点取 30 m 内最近的 OSM 特征，统计：
  - 10 m / 25 m 内可解释比例；
  - 命中的特征类别占比（最近特征，按类别计）。
- 坐标：广东 Albers 等积投影，距离单位为米。

## 结论：用哪些 OSM 边界做初始切分

选择原则：标准方案用到的特征才用；弱信号只要不是特别稀少就保留，但用
初始块数量（标准区数的 1.5–3 倍）约束总量；不使用标准方案几乎不用的
landuse/行政/围栏/公园/建筑边界。

| 特征线 | 是否用于初始切分 | 约束 |
|---|---|---|
| 主干道（motorway/trunk/primary/secondary） | 是 | 全部 |
| 三级路（tertiary） | 是 | 全部 |
| 本地路（residential/unclassified/living_street） | 是 | 建成区内全部；建成区外仅长度 ≥600 m |
| 服务路 + 步行/小径 | 是（弱） | 仅建成区内，避免乡村过切 |
| 铁路 | 是（弱） | 全部 |
| 河流/运河 | 是 | 全部 |
| 小溪/排水沟 | 是（弱） | 长度 ≥200 m |
| 水面多边形边界 | 是 | 面积 ≥0.5 ha |
| 自然植被边界（wood/scrub/grassland/wetland） | 是（弱） | 面积 ≥5 ha |
| 行政区边界（level 4–10） | 否 | 参考方案内部边界几乎不贴 OSM 行政线；市/县外框由行政面裁剪 |
| landuse 多边形、公园、公共设施、建筑 | 否 | 占比 <2%，且会引入不可解释的细碎边界 |
| 围栏/墙/路缘 | 否 | 占比 <0.15% |
| 电力线、海岸线 | 否 | 不进入初始切分；海岸由水面/陆地掩膜处理 |

同时做两件事：

1. **去除重复平行线**：双线道路先按同一 ref/name 合并中心线，再做几何
   平行合并；避免一条路产生两条紧邻边界。
2. **不做目标区数切分**：初始块完全由上述线网决定；不再用“目标面积/
   目标区数”额外切格。最终合区由 XGBoost 概率驱动，面积/区数只做很宽的
   结构约束。

## 初始块数量校准（中山，参考 538 区）

| 配置 | 初始块数 | 相对参考 |
|---|---:|---:|
| 全部本地路 + 水面/自然 + 弱路 | 1,921 | 3.57x（过多） |
| 本地路建成区 + ≥600 m，弱路建成区，自然植被≥5 ha | 1,558 | 2.90x |
| 同上 + 把 <0.02 km² 的封闭微环并入宿主，水面面块先并入邻区（采用） | 1,459 | 2.71x |
| 本地路建成区 + ≥500 m，无弱路，含自然植被 | 1,369 | 2.54x |
| 本地路仅建成区 | 777 | 1.44x（过少） |
| 无本地路 | 373 | 0.69x（过少） |

采用 **1,459 块（2.71x）**：既覆盖标准方案使用的本地路/水面/自然植被，
又保持在 1.5–3 倍区间；封闭微环和水面面块在 XGB 前先拓扑处理，避免后续
区中区。

## 后续

- 已用该切分线集重新生成 10 个城市的 4,464 个相邻块 pair，按参考微网格
  标注“是否同区”，重训合并模型（87 个特征，新增水面/小溪边界比例），
  按城市分组的 5 折交叉验证 AUC **0.964**。
- 最终合区改为概率驱动：按 XGB 概率从高到低合并相邻块，只保留单连通、
  无新增洞、紧凑度/长宽比/最大面积等结构约束；不再使用目标区数或每档
  面积硬阈值。
- 城建区小、乡村区大由线网密度和 XGB 特征自然形成；人工方格切分仅在
  完全没有选中 OSM 线的极端情况下作为最后兜底，且默认关闭。

## 2.3.6 收口验证（中山）

- 初始块 1,459（2.71x）；XGB 概率合并 889；结构收口 456；长区切分 47 个
  （两轮）+ 薄区合并 32 个 → 最终 **551 区**（参考 538，+2.4%）。
- 面积 p10/50/90 = 0.17 / 2.80 / 7.26 km²（参考 0.80 / 1.88 / 7.29）；
  长宽比 >5 为 0，最大 4.8；内环 0、多部件 0。
- 城建区 4×4 km 密集窗口本引擎 15–16 区（参考窗口 2–8 区），乡村保持大块。
- 区域属性卡按最终区与初始块面积加权重算，不再沿用单块密度。
