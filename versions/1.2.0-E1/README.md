- 参考边界中 **49.4%** 离 OSM 线 >15 m；这些“人工边界”几乎全部两端

  （核心 57.9%、农村 45.8%）；简单的中点 Bézier 弯线反而只覆盖 44.6%。
- 像素级 XGBoost（OSM 道路/水系/建筑/landuse/行政距离）预测人工边界：

  结论：**单纯补内部人工线不能突破上限**，必须和“合并/分组 + 外边界

## RL / 进化自主划线：状态、动作、奖励与可行性

**动作空间**：在 OSM 线锚点之间选一对端点，用三次 Hermite/Bézier 曲线
（端点切向连续 + 弯曲/非对称参数）生成平滑切线；不是自由画线，也不是
只会画直线。每题最多 1–2 条，且必须满足“区内无可用 OSM”门控。

**状态特征**（都已能计算）：
- 缺口：面积/周长/紧凑度/长宽比、OSM 支撑边界占比、到最近 OSM 的距离分布；
- 锚点：数量、位置、切向夹角、端点间距、端点是否接 OSM；
- 环境：道路等级密度、水系、建筑密度/边缘、landuse/POI、admin L8/L10、
  到中心距离、场景类；
- 邻域：相邻区面积/形状/密度/当前最佳 IoU 代理；
- 动作特征：弦长、弯曲度、切向连续性、面积平衡、最小块面积、紧凑度增益、
  人工线长度占比。

**奖励**：离线用参考 ΔIoU + 形状/面积/整洁性 + 人工线长度惩罚；
在线不能算真 IoU，用学习到的 value/ΔIoU 代理，超过阈值才执行。

**可行性结论（实测）**：
- 中山 top 12 多参考大区：严格门控（≥70% 内部离 OSM >30 m）下
  **可行动作 0 个**；
- 韶关乳源（OSM 稀疏县）300 次/区的进化搜索同样 **0 个可行动作**：
  这些需要切分的区附近都有 OSM，或候选曲线穿过 OSM，人工线不该画；
- 参考缺失边界的谨慎 oracle 也没有 IoU 收益；像素级预测仅
  PR-AUC 0.122。
因此：**当前数据下 RL/进化画线的期望收益低，不建议作为主攻**；
若继续，最佳路线是“离线 CMA-ES 搜索动作 + 监督蒸馏成策略模型”，
并在真正无 OSM 的稀疏区做 leave-one-city 验证，而不是在线 RL 直接试错。
更高杠杆仍是：城/乡场景分类、全局图割/合并、p50 面积分配。

- 但逐区策略（每区取模型最优动作）命中率 0.594、平均增益 0.101，
  低于手写几何启发式的 0.598 / 0.106；在中山留出考核中
  模型选出的 4–6 条动作（局部增益均 >0）把全局 IoU 压到
  0.3135–0.3138，低于启发式 4 条的 0.3225；
- 结论：局部 ΔIoU 与全局 greedy IoU 的相关性不足，动作模型暂不
  作为默认选线器；保留训练/数据管线供后续用“全局 ΔIoU”标签重训。

### 服务链路校验（参考无关）

`svc-p50c → 人工线 → p50(2.2/2.5/2.8) → need-split` 已固化进
`region_service.py`（`XGB_ART_SPLIT` / `XGB_NEED_SPLIT` 默认开），
固定随机种子。当前默认 240 次/区搜索在 svc-p50c 上确定性地选出 1 条
人工线，链路结果 `svc-chain3`：580 区、IoU 0.3224、匹配 73.4%；
把 `XGB_ART_TRIALS` 调到 1200 时选出 3 条线，链路结果
`artheur1200-need`：575 区、IoU 0.3232、匹配 73.8%。

注意：本页前面 0.3256 的 569 区文件是由历史 4 条人工线的 527 区
结果再 need-split 得到；该 4 线选择来自旧版搜索参数，当前工具无法
逐步复现。**可复现交付以 575 区（1200 trials）或 580 区（240）为准**。

## 多指标相似度（IoU 只是一个角度）

100 m 栅格 ARI、归一化 VI）、边界（F1@10/25/50 m、Chamfer、边界长度
比）、规模结构（面积分位、KS、Wasserstein、Gini）、形态（紧致度、
长宽比），并给出一个**指示性**综合分（各分项归一化后等权平均，非
