# 优化版本 2.5.10-B（中山，506 区）

在基线 `baseline/2.5.0-B` 之上，只做两处确定性修改：

1. **城区感知吸收（管线）**：新增 `_protect_urban`，0.15–0.60 km²、宽度 ≥20 m、
   urban_score ≥0.60 的紧凑城区块不参与“小/窄/低紧凑度”吸收；乡村保持强吸收。
2. **城区加密（服务层）**：按参考类面积占比给区打 core/urban/town 标签，
   对超过 1.4×类别目标面积的区，沿内部路网面或最长内部道路切 2–3 块；
   切出 <0.15 km² 的块并回邻块。

收口仍用基线的 `_enforce_zone_count`（软收口），重叠修复、12 m 平滑、
属性回填与基线一致；B2 模型与 B2 切分线组合保持不变。

## 图像复核（vision）

- 城建区密度与参考基本同量级，明显优于基线的“城区偏粗”；
- 不沿路/水的直切仍有少量（中部/南部），不是系统性问题；
- 东部沿海、北部沿河有零星狭长块，建成区内偶有串珠状小块；
- 个别小闭合块（疑似建筑/绿地）单独成块，数量少；
- 乡村大块合理，整体已非常接近参考。
