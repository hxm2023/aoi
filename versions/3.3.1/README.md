# 3.3.1（中山，509 区）——按 OSM 道路密度分配疏密

不再只用参考类面积占比，而是用每个区内部的 OSM 道路线密度（km/km²）定目标：

- 密度 ≥5：目标 0.40 km²；≥2.5：0.50 km²；切块下限 0.35；
- 密度 <1.2：按 8–16 km² 合并，外围/乡村大块；
- 长条 >4 合并；<0.30 小面吸收；45 m 拓扑一致平滑；零环/零多部件。
