- 进一步按 0.4–0.8 km² 强吸收“小/绿地”块时，核心区数从 225 降到
  151–181（版本 2.5.24/2.5.26/2.5.27），中心密度明显低于参考；
- 因此 2.5.28-B 保留 0.208 km² 以上小块，优先保证中心密度；

  最小 0.407，32 m 平滑）。
